# cf-api-restful

## Iniciar la aplicación

La página y la API se sirven desde el mismo servidor. No abras `index.html`
directamente como archivo; inicia el servidor y abre la dirección que muestra
el navegador o el reenvío del puerto 3000 en Codespaces.

1. Define `MONGODB_URI` con la cadena de conexión de MongoDB Atlas.
2. Ejecuta `npm start`.
3. Abre `http://localhost:3000/` (o la URL del puerto 3000 reenviado).

La aplicación utiliza la base de datos `tutorial10` y la colección `sensores`.
